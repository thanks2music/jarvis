# Claude Meetings（Google Meet に Claude を参加させて議事録を作る）

> 出典: [Use Claude Meetings](https://support.claude.com/en/articles/18325154-use-claude-meetings) / [Introducing Claude Meetings, now in beta](https://claude.com/resources/articles/claude-meetings) / [Release notes](https://support.claude.com/en/articles/12138966-release-notes)（2026-11-12 の項）/ [Claude Status](https://status.claude.com/) / [How transcription works（Granola）](https://docs.granola.ai/help-center/taking-notes/transcription) / [Getting consent（Granola）](https://docs.granola.ai/help-center/consent-security-privacy/getting-consent)（2026-11-19 確認）

**Claude Meetings** は、Google Meet の通話に Claude を**参加者の 1 人として**入れる機能である。2026-11-12 に beta で公開された。Claude は会話を聞いてメモを取り、質問に答え、通話中にドキュメントやホワイトボードを作る。通話が終わると、要約・アクションアイテム・文字起こしが claude.ai の**会議ページ**にまとまる。

本 doc は、Claude を Meet に参加させて議事録を作るまでの手順と運用ルールをまとめる。前提とする運用は次のとおり。

- Team プランの組織で、手順を実行する人が組織の Owner でもある
- 社外の参加者（取引先など）がいる会議もある
- 社内会議は Auto-join で自動参加させ、社外会議は参加者の同意を取ってから手動で追加する

---

## 1. できること・できないこと

| 項目 | 内容 |
|---|---|
| 対応する会議ツール | **Google Meet のみ**。他の会議ツールは「coming soon」で、時期は書かれていない |
| 提供プラン | **Team / Enterprise のみ**（claude.ai と Claude Desktop）。Free / Pro / Max では使えない |
| 使えない組織 | beta 中は一部の組織で使えない。公式は例として **Zero Data Retention（ZDR）・HIPAA-ready 構成・customer-managed encryption keys（CMEK）** の組織を挙げている（"including" で、これで全部とは限らない） |
| 既定の状態 | Team は**既定で有効**（Owner が無効にできる）。Enterprise は Owner が組織全体または一部のロールに対して有効にする |
| 通話中にできること | メモを取る、「Claude」と呼びかけるか Meet チャットに書いて質問する、ドキュメント・ホワイトボード・スライドを作らせる、本人の許可を得てその人の接続済みツール（コネクタ）を使わせる |
| 通話後に残るもの | 会議ページ（要約・アクションアイテム・文字起こし・Claude が作ったもの）と、社内の招待者へのリキャップメール |
| 保存されないもの | **音声**。保存されるのは文字起こし・要約・画面共有の説明文 |
| 最長参加時間 | **8 時間**。退出前に予告する |
| 他ツールへの文字起こし送信 | Gong・Attention・Granola・Fireflies.ai・Otter・Plaud などのパートナーと準備中で、「近く送れるようになる」とされている。2026-11-19 時点では送れない |
| 対応言語 | **公式に記載がない**。日本語の会議で文字起こしと要約がどうなるかは未検証（[§11](#11-未検証の項目とテスト通話のチェックリスト)） |

### 1.1 2026-11 の障害と復旧状況

公開直後の 2026-11-16〜17 に、想定を超える利用で Claude が多くの通話に参加できなくなった（[Claude Status](https://status.claude.com/) の "Claude unable to join meetings"）。2026-11-17 23:39 UTC 時点の状況は次のとおり。

- Enterprise: 有効なまま
- Team: **手動での追加は復旧済み**。**Auto-join は段階的に復旧中**で、完全復旧はまだ告知されていない

Auto-join を前提にする前に、Status ページでこのインシデントが resolved になったかを確認する。

## 2. 全体の流れ

```
[Owner] Google Calendar コネクタを組織で有効化
   ↓
[Owner] Organization settings > Products > Claude Meetings (beta) を設定
   ↓
[各メンバー] Meetings で Google Calendar を接続 → Auto-join と社外会議の個人設定
   ↓
[会議ごと] 社内会議: Auto-join で Claude が自動参加
           社外会議: 告知 → 同意 → 会議ページで「Add Claude」
   ↓
[通話中] 「Claude」と呼ぶか Meet チャットで依頼
   ↓
[通話後] 会議ページで要約・アクションアイテム・文字起こしを確認 → 議事録の形に整える
```

## 3. Owner の設定

Owner と Primary Owner が行う（Enterprise では、Owner アクセスを持つカスタムロールも設定ページを開ける）。

### 3.1 Google Calendar コネクタを組織で有効にする

Claude Meetings は Google Calendar から予定を読み取るため、先に組織で Google Calendar コネクタを有効にしておく必要がある。メンバーはこれが有効になって初めて、自分のカレンダーを接続できる。

### 3.2 Claude Meetings (beta) の組織設定

**Organization settings > Products > Claude Meetings (beta)** で次の 3 項目を設定する。

| 設定 | 選択肢 | 本 doc の運用での値 |
|---|---|---|
| Claude Meetings | Off / Meetings を含むロールだけ On / 全員 On | **全員 On**（Team は既定で On。Enterprise ではカスタムロールで対象を絞れる） |
| Meetings with external guests | 社内のみ / 許可 | **許可**。社外会議にも手動で Claude を入れるため。Team は既定で許可、Enterprise は既定で不許可 |
| Members' connectors in meetings | 通話中にメンバーのコネクタを Claude が使えるか | 必要に応じて決める。使うと使用量に計上される（[§8](#8-料金とデータ保持)） |

> **組織設定と個人設定の関係**: 本 doc の運用では、組織では社外会議を許可し、各メンバーの個人設定（[§4.3](#43-社外会議の個人設定をオフにする)）をオフにして Auto-join を社内会議に限る。ただし、個人設定にそこまでの効果があるかは公式に書かれておらず、**想定である（要実測）**。
>
> 注意: 公式が「社外の人が招待されていれば参加しない」「途中で社外の人が入れば退出する」と書いているのは、組織で社外会議を**許可していない**場合だけである。許可した組織では、社内会議に途中から社外の人が入っても、Claude が自動で退出するとは書かれていない（[§5.1](#51-社内会議auto-join)）。より安全側に倒すなら、組織設定を「社内のみ」にして社外会議では Claude を使わない運用もある。

## 4. メンバーの設定

### 4.1 Google Calendar を接続する

1. claude.ai（または Claude Desktop）で **Meetings** を開く
2. **Google Calendar を接続する**

接続すると、Meetings のカレンダーに過去と今後の会議が並ぶ。

### 4.2 Auto-join を設定する

**Settings > Capabilities > Meetings > Auto-join** で、Claude を自動で参加させる範囲を選ぶ。

| 選択肢 | 対象 |
|---|---|
| All meetings | 全会議 |
| All meetings except one-on-ones | 1on1 以外の全会議 |

- Auto-join は**本人しか設定できない**。Owner が代わりに有効にすることはできない
- 1on1 を記録したくなければ、後者を選ぶ

### 4.3 社外会議の個人設定をオフにする

各メンバーにも **Meetings with external guests** の個人設定がある（Settings > Capabilities > Meetings）。本 doc の運用では**オフ**にする。社外の参加者がいる会議に Auto-join で Claude が入るのを防ぐ狙いである。

> ⚠️ **要実測**: 公式は個人設定があることしか書いておらず、オフにしたときの効果（社外の人が招待された会議に Auto-join で入らなくなるか）は書かれていない。Auto-join を広く有効にする前に、テスト通話で確かめる（[§11](#11-未検証の項目とテスト通話のチェックリスト)）。

> ⚠️ **要実測**: 個人設定をオフにしたとき、会議ページから手動で「Add Claude」した社外会議に Claude が入れるかは、公式ヘルプに書かれていない。入れない場合は、社外会議の直前だけ個人設定をオンにし、終わったら**必ずオフに戻す**運用になる。オンの間は、同じ時間帯にある別の社外会議にも Auto-join で入りうる点に注意する。テスト通話で確かめる（[§11](#11-未検証の項目とテスト通話のチェックリスト)）。

## 5. 会議ごとの運用

### 5.1 社内会議（Auto-join）

設定が済んでいれば、Claude は会議に自動で参加する。Auto-join を有効にする前に、**社内のメンバーにも文字起こしされることを伝えておく**。公式も、Claude を追加したり Auto-join を有効にしたりする前に、参加者全員が文字起こしを了承しているか確認するよう求めている。

社内会議の途中で社外の人が入ってきた場合、組織で社外会議を許可していると、Claude が自動で退出するとは公式に書かれていない。その人の了承が取れていなければ、ホストが Claude に退出を頼むか、会議ページで **Remove Claude** を押す。

### 5.2 社外会議（手動で追加）

1. 招待文で、Claude が参加して文字起こしすることを伝え、了承の返信をもらう（[§7](#7-社外参加者への告知文テンプレ)）。返信が無いことを了承とみなさない
2. 了承が取れなければ Claude を入れない
3. 会議の冒頭で口頭でも告知し、招待文を読んでいない参加者を含めて全員の了承を確かめる
4. 了承が取れてから、claude.ai の **Meetings** でその会議を選び、**Add Claude** を押す

公式は「追加する前に」全員の了承を確かめるよう求めているため、追加は告知の後にする。

社外参加者がいる会議での Claude の挙動は、社内会議と違う。

| 項目 | 挙動 |
|---|---|
| メモと文字起こし | 取る。社外参加者の発言も文字起こしと要約に含まれる |
| Meet チャット | 告知を投稿するが、**質問には返答しない** |
| 会議ページ・リキャップメール | 社外参加者には共有されない |
| 社外会議を許可していない場合 | Claude は参加しない。社内会議の途中で社外の人（**他社の議事録 bot を含む**）が入ってくると、**Claude は退出する** |

### 5.3 入室・一時停止・退出

| 操作 | 方法 |
|---|---|
| 入室 | 通常は確認なしで参加する。入室確認が出た場合はホストが許可する。ホストが拒否すると、誰かが再度追加しない限り Claude は再試行しない（拒否されたことは会議ページに表示される） |
| 一時停止 | 「聞くのを止めて」と頼むか、会議ページから止める |
| 再開 | 会議ページから再開する |
| 退出 | 「退出して」と頼むか、会議ページで **Remove Claude** を押す |
| 状態の確認 | Claude のタイルに現在の状態が表示される |

Claude は参加すると、Meet チャットに会議ページへのリンクを投稿する。

## 6. 議事録を作る

### 6.1 通話中に頼む

- 「Claude」と呼びかけるか、Meet チャットに書く。返答は**既定で Meet チャットに書かれる**
- **Meet チャットへの投稿は参加者全員に見える**。人事や評価など、全員に見せたくない内容は通話中に頼まない
- 接続済みツールを使う依頼では、Claude は本人の許可を取る。初回だけ確認され、以後は許可が続く。声での依頼は、毎回誰が話しているかを確認する
- ドキュメント・ホワイトボード・スライドは、チームの誰でも頼める。作ったものは会議ページに添付される

### 6.2 通話後に会議ページを見る

会議ページには次のものが残る。

- 要約
- アクションアイテム
- 文字起こし
- Claude が作ったもの（ドキュメント・ホワイトボードなど）

招待に入っていた**社内メンバー**には、会議ページへのリンク付きのリキャップメールが届く。招待に入っていた社内メンバーは、メモを見て、Claude が作ったものを編集できる。会議ページは組織内の他の人にも共有できる。社外会議の会議ページを共有すると、社外参加者の発言の文字起こしも共有される点に注意する。

### 6.3 議事録の形に整える

自動の要約はそのままでも使えるが、決まった形の議事録にしたい場合は、次の文面で Claude に頼む。通話の終わり際に Meet チャットで頼むか（社内会議のみ。社外参加者がいるとチャットでは返答しない）、通話後に claude.ai の通常のチャットで頼む。claude.ai のチャットでは、アクセス権のある過去の会議について質問できる。

```
<会議名>（<日付>）の議事録を、次の形式で日本語で作ってください。

## 会議情報
- 日時 / 参加者

## 決定事項
- 決まったことを 1 行ずつ

## TODO
| 内容 | 担当 | 期限 |

## 未決事項・課題
- 結論が出なかった論点と、次に誰が何をするか

## 補足
- 数字・固有名詞など、文字起こしから正確に拾うべきもの

文字起こしに無いことは書かず、担当や期限が発言に無ければ「未定」と書いてください。
```

最後の 1 文は、推測で担当や期限を埋めさせないためのものである。

## 7. 社外参加者への告知文テンプレ

### 7.1 招待文に入れる文面

```
本会議では、議事録作成のため AI アシスタント（Claude）が参加者として入室し、
会話を文字起こしします。音声は保存されません。保存されるのは、文字起こし・要約・
画面共有の内容の説明文です。
差し支えないか、ご返信いただけますでしょうか。ご了承いただけない場合は Claude を参加させません。
```

### 7.2 会議の冒頭で伝える文面

```
本日は議事録のため Claude という AI が参加しています。会話は文字起こしされます。
差し支えがあれば、今お知らせください。
```

文字起こしされたくない人がいれば、Claude に退出を頼むか、会議ページで **Remove Claude** を押す。

## 8. 料金とデータ保持

| 項目 | beta 中の扱い |
|---|---|
| メモ・文字起こし | Team / Enterprise に含まれる（追加料金なし） |
| 通話中の回答 | 接続済みツールを使わない回答は含まれる |
| 通話中に作ったドキュメント・ホワイトボード | **2027-02-10 まで無料** |
| 接続済みツールの利用 | 依頼した本人の使用量に計上され、組織に課金されることがある |
| 保存されるもの | 文字起こし・要約・画面共有の説明文。**音声は保存しない** |

## 9. Claude Code から会議を参照できるか

**2026-11-18 に試した時点では参照できなかった**（実測。公式 docs に記載は見つかっていない）。Claude Code のセッションに claude.ai の Meetings コネクタ（`list_meetings` などのツール）は表示されるが、呼ぶと「`user:projects:read` 権限が無い」というエラーになった。エラーメッセージは claude.ai または Claude Desktop から使うよう案内し、「公開版の Claude Code はこの権限を要求しないため、再ログインしても解決しない」という趣旨の説明を返した。

会議の内容を扱うときは、claude.ai か Claude Desktop のチャットで質問するか、会議ページから議事録をコピーして使う。

## 10. Granola との併用

Granola は会議に bot を参加させず、PC のシステム音声を取り込んで文字起こしする（[How transcription works](https://docs.granola.ai/help-center/taking-notes/transcription)）。会議の参加者一覧に Granola は現れない。

- Claude Meetings は、他社の議事録 bot が会議に入ってくると退出する（社外参加者を許可していない場合）。Granola は bot ではないため、この条件には当たらないと考えられる。ただし同じ会議で両方を動かした実績はまだない
- 2 つを同時に使うと、同じ会議の文字起こしが 2 か所に残る。どちらを正本にするかを決めておく
- Claude Meetings から Granola へ文字起こしを送る連携は準備中で、まだ使えない
- Granola は参加者一覧に現れないため、社外会議で Granola も使う場合は、[§7](#7-社外参加者への告知文テンプレ) の告知に Granola の文字起こしも含める。Granola も、他の人を文字起こしするときは参加者に知らせることを勧めている（[Getting consent](https://docs.granola.ai/help-center/consent-security-privacy/getting-consent)）

| 観点 | Claude Meetings | Granola |
|---|---|---|
| 参加の仕方 | 参加者として入室する | bot は入らない（手元の PC で録る） |
| 対応する会議ツール | Google Meet のみ | Meet・Zoom・Teams など |
| 通話中の作業 | 質問への回答、ドキュメント作成、コネクタ利用 | 手元のメモの補強 |
| 共有 | 社内の招待者に会議ページとリキャップメール | Granola 上で共有 |

## 11. 未検証の項目とテスト通話のチェックリスト

次の項目は公式に記載がないか、2026-11-19 時点で実測していない。社内だけの短いテスト通話で確かめ、結果を本節に追記する。

- [ ] **日本語の文字起こし**: 日本語の会話が正しく文字起こしされるか。固有名詞や数字の精度
- [ ] **要約の言語**: 日本語の会議で、要約とアクションアイテムが日本語で出るか
- [ ] **日本語での呼びかけ**: 日本語の会話の中で「Claude」と呼んで反応するか
- [ ] **個人の社外会議設定と Auto-join**: 個人の「Meetings with external guests」がオフのとき、社外の人が招待された会議に Auto-join で Claude が入らないか（Auto-join を広く有効にする前に確かめる）
- [ ] **途中から入った社外の人**: 組織で社外会議を許可した状態で、社内会議の途中に社外のアカウントが入ったとき、Claude が退出するか
- [ ] **個人の社外会議設定と手動追加**: 個人の「Meetings with external guests」がオフのとき、手動で追加した社外会議に Claude が入れるか（[§4.3](#43-社外会議の個人設定をオフにする)）
- [ ] **Auto-join の復旧**: Team で Auto-join が動くか（[§1.1](#11-2026-11-の障害と復旧状況)）
- [ ] **Granola との同時利用**: Granola を動かしたまま Claude が退出せずに残るか
- [ ] **リキャップメール**: 招待者に届くか、届くまでの時間
- [ ] **参加のタイミング**: Auto-join で Claude が会議のどの時点で入室するか
