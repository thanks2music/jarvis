## B. 事実誤り・廃止仕様の修正 (高優先)

### 3. mcp-setup.md / config-files.md — MCP local/user スコープの保存先が誤り
- **現状 doc**: 「`local` → `.claude/settings.local.json`」「`user` → `~/.claude/settings.json`」。
- **公式最新**: MCP サーバーの **local / user スコープはいずれも `~/.claude.json`** に保存される (project のみ `.mcp.json`)。公式は「local-scoped MCP servers は `~/.claude.json` に保存され、通常の local settings (`.claude/settings.local.json`) とは別物」と明示。
- **対応案**: 両 doc の MCP スコープ対応表を訂正。
- **出典**: https://code.claude.com/docs/en/mcp

### 4. mcp-setup.md — SSE トランスポートが非推奨化 + WebSocket 追加
- **現状 doc**: `sse` を `http` と並列の有効な選択肢として記載。
- **公式最新**: 「The SSE transport is deprecated. Use HTTP servers instead」。新たに **WebSocket (`ws`) トランスポート**が追加 (doc に記載なし)。
- **対応案**: `sse` に非推奨注記、`ws` を追加。トランスポート選択指針を更新。
- **出典**: https://code.claude.com/docs/en/mcp

### 5. config-files.md — permission モードが 6 種に (auto / dontAsk 追加)
- **現状 doc**: permission モードを `default / acceptEdits / plan / bypassPermissions` 前提で記述。
- **公式最新**: 6 種 — `default`, `acceptEdits`, `plan`, **`auto`**, **`dontAsk`**, `bypassPermissions`。`defaultMode` で指定、`disableAutoMode` で無効化可能。
- **対応案**: モード一覧を更新。`defaultMode` の説明を追加。
- **出典**: https://code.claude.com/docs/en/permissions , https://code.claude.com/docs/en/glossary

### 6. skills.md — effort 値・モデル制約・description バジェットの修正
- **現状 doc**: `effort` = 「`low/medium/high/max` (Opus 4.6 のみ)」。description バジェット = 「コンテキストの 2% / フォールバック 16,000 文字」、確認は `/context`。
- **公式最新**:

- **対応案**: 値・制約・バジェット数値・確認コマンドを訂正。
