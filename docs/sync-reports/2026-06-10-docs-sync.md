## 把握した公式事実（裏取り済み・憶測なし）

| 項目 | Fable 5 | Mythos 5 |
|---|---|---|
| 位置づけ | Anthropic の最高性能の**一般提供**モデル（Mythos-class） | Fable 5 と**同一基盤モデル**だが一部 safeguards 解除版 |
| 提供形態 | 2026-06-09 GA（API / AWS / Bedrock / Vertex / Foundry / claude.ai / Claude Code） | **GA なし**。Project Glasswing 承認顧客のみ（limited availability） |
| model ID | `claude-fable-5`（日付サフィックスなし） | `claude-mythos-5` |
| 料金 | $10 / input MTok・$50 / output MTok | 同左（Mythos Preview の半額以下） |
| context / max output | 1M / 128k tokens | 同左 |
| 安全分類器 | あり（サイバー/生物等の要求は default Opus に自動フォールバック） | なし（同能力で分類器を解除） |
| データ保持 | 30 日保持・ZDR 非対応（Covered Models） | 同左 |

ClaudeCode 固有の挙動（[model-config](https://code.claude.com/docs/en/model-config) で裏取り）:

- **新エイリアス**: `fable`（Fable 5 を選択）、`best`（access があれば Fable 5、無ければ最新 Opus）。`/model fable` で選択し user settings に保存
- **`opus` / `sonnet` / `haiku` の解決先は変更なし**（`opus`→Opus 4.8、`sonnet`→Sonnet 4.6 のまま。Messages API も unchanged）
- **effort デフォルト = `high`**（Opus 4.8 と同じ）。レベル: `low / medium / high / xhigh / max`
- **thinking 分類**: Extended thinking = **No** / Adaptive thinking = **Yes（always on）**。Fable 5 は thinking を OFF にできない（`MAX_THINKING_TOKENS=0` / `alwaysThinkingEnabled` / セッショントグル無効、`CLAUDE_CODE_DISABLE_ADAPTIVE_THINKING` 非対応）
- **automatic model fallback**: 安全分類器がフラグした要求は default Opus（API/gateway は Opus 4.8、AWS は Opus 4.7）で再実行。`claude --safe-mode` で切り分け
- **必須バージョン**: Claude Code **v2.1.170 以降**（旧版は picker に Fable 5 を出さない）。ZDR 下では非提供
- **tokenizer**: Opus 4.7 導入の tokenizer を使用（4.7 より前のモデル比で同テキストが約 30% 多くトークン化）
- **新環境変数**: `ANTHROPIC_DEFAULT_FABLE_MODEL`、`DISABLE_PROMPT_CACHING_FABLE`
- **fast mode**: 3 ソースとも**言及なし** → ドキュメント化では「記載なし」とし、憶測で書かない
- **auto mode 対応モデルリスト**: best-practices / permission-modes に Fable 5 / Mythos 5 は**現時点で未追加**（公式が列挙していない。これも事実として扱う）
- **プラン**: 6/9〜6/22 は Pro / Max / Team / Enterprise に追加費用なしで同梱。**6/23 に削除**され、以降は usage credits 必要
