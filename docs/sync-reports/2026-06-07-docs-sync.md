### 6. [既存追記] dynamic workflows の公式体系化（harness.md）
- 追記先: `docs/harness.md` の Opus 4.8 / ultracode セクション
- 要点: ブログ 2 本で dynamic workflows の設計思想が公式に体系化された:
  - **概念**: 「Claude がタスクごとに専用ハーネスをその場で書く」。固定の Planner/Generator/Evaluator の限界を超える位置づけ。
  - **公式の 3 failure mode**: "Agentic laziness"（タスク未完）/ "Self-preferential bias"（自己優遇）/ **"Goal drift"（ターン跨ぎの制約喪失、新軸）**。現行の「Context Anxiety」「Self-Evaluation Bias」を補強。
  - **compositional パターン 6 種**: Classify-and-act / Fan-out-and-synthesize / Adversarial verification / Generate-and-filter / Tournament / Loop-until-done。
  - 運用: 数百並列 subagent で大量トークン消費 → scoped task から始める + auto mode 併用推奨。
- 出典: https://claude.com/blog/introducing-dynamic-workflows-in-claude-code (2026-05-28) / https://claude.com/blog/a-harness-for-every-task-dynamic-workflows-in-claude-code (2026-06-02)

### 9. config-files.md / best-practices.md — `acceptEdits` の自動承認コマンド範囲が古い
- 該当箇所: config-files.md のパーミッションモード表、best-practices.md の同記述

### 10. config-files.md / best-practices.md — auto mode のプロバイダ要件・bypassPermissions 挙動
