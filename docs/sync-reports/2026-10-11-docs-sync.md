### 18. [新規ファイル or 既存追記] Mods — Claude Code に割り込む関数 hook を持つ plugin

- 反映先: docs/mods.md (案 A) / docs/plugins.md + docs/hooks.md (案 B)
- 要点:
  - mods は TS / JS の関数で、Claude Code のイベント (ツール呼び出し・権限要求・描画など) の前・後・代わりに処理を差し込む。書き換え・ブロック・UI 追加ができ、hooks ではできなかった操作が可能 (CLI v2.1.287+ / Desktop v2.1.286+、既定 ON)
  - plugin の `hooks/hooks.json` の `modules` として配布する。sandbox の外で本体と同じ権限で動き、ask ルールを越えて承認でき classifier も通らない。組込みの `sec-default` が deny の上書きを防ぐ。組込みの `/diff` パネルや AGENTS.md 対応も mod
  - 管理: `allowManagedModsOnly` / `allowModsToOverrideDenyRules` / `prependPlugins`。インストール済みの mod を止めるのは `disableAllHooks` / `--bare` / `--safe-mode` で、組込み mod はこれらでは止まらない。インストール済みの mod は `claude -p` / Agent SDK でも hooks が動く
  - **フェーズ2 での訂正 (2026-10-11)**: 承認時の本項には「`-p`・dontAsk・未信頼 workspace・`--bare`・`disableAllHooks` では読み込まれない」と書いていた。前の 3 条件は Claude が書いて承認待ちになっている mod だけの条件 (mods/create) であり、全 mod の条件ではない (mods/overview の「Where mods run」表)。反映した docs/mods.md は公式どおりに書き分けた
  - **案 A (推奨)**: 公式に 10 ページ (overview / create / events / interface / api / reference / test / troubleshoot / admin / gallery) ある独立機能なので `docs/mods.md` を新設し、plugins.md と hooks.md から 1 段落でリンクする
  - 案 B: plugins.md に「hooks module (mods)」節、hooks.md の「Hooks と他の拡張機能の違い」に比較行を追加するだけにとどめる
  - Zed (ACP) で描画が出るかは公式の動作環境表に無く未確認
- 出典: https://code.claude.com/docs/en/plugins/mods/overview / https://code.claude.com/docs/en/plugins/mods/admin / https://claude.com/resources/articles/claude-code-mods
