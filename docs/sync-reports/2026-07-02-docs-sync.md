### 4. [事実誤り] Explore subagent = Haiku 固定は撤回された(v2.1.198)
- **該当箇所**: `docs/sub-agents.md` 組み込みサブエージェント表、`docs/best-practices.md`(Explore への言及部分)

- **公式最新**: **v2.1.198 で撤回**。Explore は **メインセッションの model を継承**(ただし Opus で cap する)。従来 Haiku 固定だった説明は不正確に
- **対応案**: sub-agents.md の該当行を「メインから継承(Opus で cap)」に更新。前回 2026-06-18 の是正情報を新 fact で上書き
- **出典**: CHANGELOG v2.1.198(https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

### 5. [事実誤り] Foreground subagent も 5-level 深度制限(v2.1.181)
- **該当箇所**: `docs/sub-agents.md`「新しいサブエージェント機能(実行形態の拡張)」の「Nested subagents」節
- **現状**: 「foreground は任意深度で spawn 可(各段が親をブロックするため self-limiting)、background は depth 5 で Agent ツールが付与されず以降 spawn 不可」
- **公式最新**: **v2.1.181 で foreground も 5-level cap**。resumed / forked subagent は spawn depth を継承・カウントする。「fg unlimited self-limiting」は不正確
- **対応案**: sub-agents.md 該当行を「fg / bg どちらも depth 5 cap、resumed/forked は継承」に更新
- **出典**: CHANGELOG v2.1.181, v2.1.187

### 6. [事実誤り] `sonnet` エイリアス解決先変更(項目 1 の一部だが影響大のため独立)
