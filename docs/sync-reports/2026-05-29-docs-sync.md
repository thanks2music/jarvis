## A. 新規ドキュメント作成案（独立した大型機能）

### 1. [新規] Hooks 専用ドキュメント
- 配置案: `docs/hooks.md`
- 要点: 現状 Hooks は best-practices.md 内に一節があるのみで専用 doc が無い。一方 Hooks は新機能が急増（`effort.level`/`$CLAUDE_EFFORT` 連携、`type: "mcp_tool"`、`args: string[]` exec 形式、`PostToolUse` の `continueOnBlock`/`updatedToolOutput`、`terminalSequence`、`PreCompact` のブロック、`UserPromptSubmit` での session title 設定、`defer`）。Skills/Plugins/SubAgents が独立 doc を持つ以上、Hooks も独立させるのが整合的。
- 出典: https://code.claude.com/docs/en/hooks
- 連動更新: README.md（英/日 目次）, CLAUDE.md（構造ツリー + 参照リスト）

### 2. [新規] Dynamic workflows ドキュメント
- 配置案: `docs/workflows.md`
- 要点: Opus 4.8 と同時に Claude Code v2.1.154 で追加（research preview）。Claude が JS オーケストレーションスクリプトを書き、ランタイムが最大 16 並列・1 run 最大 1,000 エージェントを実行。中間結果はスクリプト変数に保持し最終結果のみコンテキストに返す。`/effort ultracode` で xhigh + 自動 workflow orchestration。**ハーネスの Generator/Evaluator パターンのネイティブ機能化**であり、本リポの harness.md と密接に関連する重要機能。
- 出典: https://code.claude.com/docs/en/workflows, https://www.anthropic.com/news/claude-opus-4-8
- 連動更新: README.md, CLAUDE.md, harness.md との相互リンク

### 3. [新規] Claude Code on the web / クラウド実行系ドキュメント
- 配置案: `docs/claude-code-on-the-web.md`
- 要点: 既存 docs に未カバーのクラウド実行系をまとめる。Routines（スケジュール/GitHub イベント/API 発火のテンプレートエージェント、`/fire` エンドポイント）、`/schedule`、`/autofix-pr`（CI/レビュー監視で green まで自動 push）、Ultraplan。
- 出典: https://code.claude.com/docs/en/routines, https://code.claude.com/docs/en/claude-code-on-the-web
- 連動更新: README.md, CLAUDE.md

### 4. [新規] Agent view / 並列セッション管理ドキュメント
- 配置案: `docs/agent-view.md`（または sub-agents.md の並列セッション節を大幅拡張）
- 要点: `claude agents` で全セッションを 1 画面管理（実行中/入力待ち/完了）。dispatch flags（`--model`/`--effort`/`--permission-mode`）でバックグラウンドセッション構成。Monitor tool（バックグラウンド watcher）、Remote Control + mobile push notifications もここに含められる。Agent teams とは別概念。
- 出典: https://code.claude.com/docs/en/agent-view, https://code.claude.com/docs/en/remote-control
- 連動更新: README.md, CLAUDE.md
- 補足: 大型だが粒度判断は BOSS に委ねたい（独立 doc か sub-agents.md 拡張か）
