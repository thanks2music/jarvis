## B. 仕様変化（更新必要）

### 3. sub-agents.md — nested subagents が公式機能化（v2.1.172）
- 現状: 「nested SubAgent は使わない（フラット並列）」（JARVIS Plugin の運用方針として記述）
- 公式最新: v2.1.172 以降、**subagent が自身の subagent を spawn 可能**。background チェーンは 5 階層上限、foreground は self-limiting。`/agents` でツリー表示。fork は別 fork を spawn 不可だが他種別は可。
- 対応案: 「公式機能としては nested 可能（v2.1.172〜）」を事実として追記し、「JARVIS Plugin の運用方針としてはフラット並列を採る」と**レイヤーを分けて**整理。
- 出典: https://code.claude.com/docs/en/sub-agents

### 4. sub-agents.md — persistent memory のパス具体化
- 現状: `memory: user|project|local`（パス未記載）
- 公式最新: `user`=`~/.claude/agent-memory/<name>/` / `project`=`.claude/agent-memory/<name>/` / `local`=`.claude/agent-memory-local/<name>/`。MEMORY.md は先頭 200 行 or 25KB ロード。
- 出典: https://code.claude.com/docs/en/sub-agents

### 5. sub-agents.md — 同名 subagent の cwd 最近接解決（v2.1.178）
- 公式新記述: ネストした `.claude/agents/` に同名 `name` が複数ある場合、**cwd に最も近い定義を採用**。
- 対応案: 優先順位表に補足。
- 出典: https://code.claude.com/docs/en/sub-agents

### 6. best-practices.md / harness.md — model alias 解決のプロバイダ別分岐
- 現状: 「`opus` エイリアスは Opus 4.8 のまま据え置き」（Anthropic API 前提のみ）
- 公式最新: プロバイダ別に分岐。**Anthropic API**: `opus`→Opus 4.8 / `sonnet`→Sonnet 4.6。**Claude Platform on AWS**: `opus`→Opus 4.7。**Bedrock/Vertex/Foundry**: `opus`→Opus 4.6 / `sonnet`→Sonnet 4.5。Fable 5 の fallback 先も AWS では Opus 4.7。
- 対応案: 「Anthropic API では」と限定し、プロバイダ別表を追記。
- 出典: https://code.claude.com/docs/en/model-config

### 7. config-files.md — Windows managed settings に Group Policy 追加

## D. 新設定・新オプション（config-files.md / best-practices.md 追記）

### 12. settings 新フィールド群
- `advisorModel`(v2.1.98+) / `enforceAvailableModels`+`availableModels` 厳格化(v2.1.175+、managed) / `footerLinksRegexes`(v2.1.176+) / `language`(v2.1.176+、セッションタイトル言語) / `autoMode`（classifier カスタム: environment/allow/soft_deny/hard_deny）/ `attribution`（commit/PR 署名カスタム）/ `subagentStatusLine` / `disableBundledSkills`（+`CLAUDE_CODE_DISABLE_BUNDLED_SKILLS`）。
- 出典: https://code.claude.com/docs/en/settings

### 13. permission 構文の拡張
- deny rule の tool 名に **glob** 可（`"*"` で全ツール拒否、未知ツール名は起動時警告）。
- `Tool(param:value)` 構文でツール入力パラメータをワイルドカードマッチ（例 `Agent(model:opus)` で Opus サブエージェントをブロック、v2.1.178）。
- 出典: https://code.claude.com/docs/en/settings / https://code.claude.com/docs/en/permissions

### 14. --safe-mode / CLAUDE_CODE_SAFE_MODE（v2.1.169）
- 全カスタマイズ（CLAUDE.md/skills/plugins/hooks/MCP/custom commands・agents）を無効化して起動。認証/モデル/組込ツール/権限は有効。設定起因の不具合切り分け用。
- 対応案: config-files.md か best-practices.md のトラブルシュート文脈に追記。
- 出典: https://code.claude.com/docs/en/debug-your-config

### 15. その他の挙動・オプション
- `/config key=value`（プロンプトから設定変更、interactive/`-p`/Remote Control 対応、v2.1.181）/ `sandbox.allowAppleEvents`(v2.1.181) / auto mode の **subagent spawn 事前審査**(v2.1.178) / cross-session messaging hardening（他セッション中継メッセージは user authority を持たず auto mode がブロック）。
- 出典: https://code.claude.com/docs/en/whats-new / changelog
