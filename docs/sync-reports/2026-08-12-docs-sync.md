## B. 【新機能】v2.1.222 〜 v2.1.227 + 公式新ページ

### 11. **auto mode が 2026-08-14 から既定 permission mode に** (Pro / Max / Team)

BOSS は Max プランのため**直接影響する**。

- 「**Starting August 14, 2026, auto mode becomes the default permission mode for new sessions on Pro, Max, and Team plans.**」Enterprise / API / AWS / Google Cloud / Microsoft Foundry は引き続き opt-in
- 自分で既定を設定済みなら維持 (一度だけ切替プロンプト)。組織が managed settings で pin していれば不変
- **auto mode の classifier 呼び出しは usage limit に計上されなくなった** (適用済み)
- **一時停止の閾値**: classifier ブロックが 3 回連続 or セッション累計 20 回で auto mode を抜けて prompt に戻る (設定不可)
- 正式キー名は **`permissions.disableAutoMode`**。`"disable"` で `Shift+Tab` サイクルから消え `--permission-mode auto` も起動時に拒否
- 反映先: `docs/best-practices.md` (最優先) / `docs/config-files.md`
- 出典: https://claude.com/blog/auto-mode-default-in-claude-code / https://code.claude.com/docs/en/permission-modes

> **補足**: `~/.claude/work-style.md` の「長時間自律実行は `--dangerously-skip-permissions` ではなく `--permission-mode auto` を第一選択」という個人ルールは、既定化により「明示指定が不要になった」形で更新余地がある。**本スキルのスコープ外**のため、指摘に留める。

### 12. **Cross-session messaging** (v2.1.224) — 新機能領域が丸ごと未記載

- 独立セッション同士が `ListAgents` で相互発見し `SendMessage` でテキストを送受信。**会話履歴やファイルは渡らない**。macOS / Linux のみ。Bedrock / AWS / GCP / Foundry 非対応
- v2.1.225 で Remote Control 経由で**他マシンのセッション**にも名前で送信可能
- 新コマンド `/list-agents` (alias `/peers`)、`/status` に `Peer address` 行
- 新設定: `crossSessionInbound` (accept/hold/refuse、既定は両セッションの permission mode クラスで自動決定。bypass 側が受け手なら hold) / `dialogExpiry` (保留ダイアログ期限、既定 5〜10 分、`"never"` 可、`-p` にも適用) / `isolatePeerMachines` (マシン外送信に毎回承認。bypassPermissions でも要求)
- 新 env: `CLAUDE_CODE_MESSAGING_SOCKET` (SessionStart 前から hook / Bash に export)
- 反映先: `docs/sub-agents.md` + `docs/slash-commands.md` + `docs/config-files.md` (※ 新規ファイル化の是非は要判断 J-2)
- 出典: https://code.claude.com/docs/en/cross-session-messaging / https://code.claude.com/docs/en/whats-new/2026-w32

### 13. **Claude Security plugin** (公式新ページ)

- `/plugin install claude-security@claude-plugins-official` → `/claude-security`。多エージェントで脅威モデル作成 → 脆弱性探索 → **独立検証**、`CLAUDE-SECURITY-<timestamp>/` に出力
